# deep-south-today-data-test

# About the Project
- This project analyzes Mississippi education data to identify anomalies in student performance among varying demographics, with a particular emphasis on students with disabilities. 

# Built With
- pandas, numpy, altair, glob

# Getting Started
- Go to the [Mississippi Succeeds Report Card](https://msrc.mdek12.org/) page of the Mississippi Department of Education website. Scroll down to the "All Data" section. Click "select a year to download" and download all available years. After downloading, convert them to csvs, and then upload the csvs to a "data" folder in your VS Code folder. 

If you want to read more information about the data, [click here](chrome-extension://efaidnbmnnnibpcajpcglclefindmkaj/https://msrc.mdek12.org/downloads/MSRCUserGuide.pdf)
