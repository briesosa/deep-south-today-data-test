# deep-south-today-data-test

# About the Project
- This project analyzes Mississippi education data to identify anomalies in student performance among varying demographics, with a particular emphasis on students with disabilities. 

# Built With
- pandas, numpy, altair, glob

# Getting Started
- Go to the [Mississippi Succeeds Report Card](https://msrc.mdek12.org/) page of the Mississippi Department of Education website. Scroll down to the "All Data" section. Click "select a year to download" and download all available years. After downloading, convert them to csvs, and then upload the csvs to a "data" folder in your VS Code folder. 

If you want to read more information about the data, [click here](https://msrc.mdek12.org/downloads/MSRCUserGuide.pdf).

- Download [Mississippi's dropout stats](https://mdek12.org/wp-content/uploads/sites/33/2025/02/Grad-Dropout-Rates-2025-Report.pdf) from the 2025-2026 school year. Navigate to Attachment 2 on page 12, copy the chart from page 12-16 and paste into an Excel spreadsheet. Convert the spreadsheet into a csv and upload the csv to the "data" folder in your VS Code folder. 

Run cells in the analysis.ipynb notebook to conduct analysis.
